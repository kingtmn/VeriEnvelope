# ADR-004 Pilot 对象先选 MCP Server

## Context

第一阶段允许的类型只有 tool 和 mcp_server。需要决定以后第一批真实组件测哪一种。现在还不能执行它们。

Skill、Agent、Multi-Agent 和工作流不在这道决定里。

## Decision

以后的第一个真实 Pilot 类别选 MCP Server。当前 runner 不因此增加 MCP 客户端，也不运行任何外部服务器。

## Reason

MCP 有固定的观察窗口：初始化、工具列表、工具调用和约定的请求响应。能力陈述可以写成“对这个输入，工具返回什么”。权限和传输方式本身就落在 Envelope 里。

命令行工具没有这种公共边界。两个评估者很容易测到不同的旗标和副作用，P3 会先败在接口不固定，而不是败在组件。

这不等于 MCP 进程是安全的。协议边界不是沙箱。

## Trade-offs

MCP 服务器通常仍然是任意代码，还可能要网络。在隔离落地之前，这个决定只约束“以后写哪种方法”，不授权运行。

如果第一批真实尝试证明工具列表并不比 CLI 更容易写成稳定陈述，这个 ADR 应被新的证据改掉，而不是继续维护它。

## Status

Accepted
