# ADR-001 事实来源是仓库里的记录

## Context

结论如果只存在于网页或数据库字段里，后来的人无法回答“当年为什么这样判断”。查看器又最容易被误当成权威界面。

## Decision

Git 仓库中的方法、schema、证据包和结果 JSON 是事实来源。HTML 查看器是人读界面，不保存第二套结论，也不在打开时重新打分。

历史以追加事件保存。代码拒绝在一次更新里截断已有事件。已经提交的 Git 对象如果被强行改写，这超出程序能保证的范围，仍然违反宪法。

## Reason

证据包可以离开数据库单独阅读。查看器坏了，结论还在。

## Trade-offs

仓库会逐渐积累原始输出，体积会涨。现阶段没有外部证据，这个问题还没出现。不引入数据库来“解决”一个尚未发生的规模问题。

## Status

Accepted
